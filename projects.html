Current work

Fall 2026 – Present · Argonne National Laboratory

Understanding and reducing LLM API costs

I’m exploring how context length, request patterns, and repeated tool interactions affect the cost of LLM-based applications. The goal is to identify user-level strategies that make these systems less expensive to run.

Research context →

2026 · Manuscript in progress

Token economics of LLM inference

A survey organizing the different ways tokens contribute to inference cost, from the initial prompt to intermediate reasoning, output generation, and tool calls. I’m particularly interested in connecting optimization techniques to what an API user can actually control.
