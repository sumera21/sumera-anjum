🔬 Research Projects

Beyond Vibe Coding: Multi-Framework Quantum Code Generation and Execution-Aware Evaluation with LLMs

Jan 2026 – Oct 2026

Developed a quantum code generation pipeline by fine-tuning Microsoft Phi-4 (14B) with LoRA and GRPO, using execution-aware rewards across PennyLane, Qiskit, and OpenQASM. Evaluated 23,010 framework-specific instances and 1,149 held-out prompts for executability and quantum-state fidelity.

LLM-Driven Hardware Design for Quantum Simulation Acceleration

May 2026 – Aug 2026

Evaluated LLM code generation for quantum simulation accelerators, checking quantum circuits and latency against ground-truth Chisel baselines using Python and JSON circuit specifications.

ProMCP: Profiling Token Flows in MCP-Based LLM Agents

Aug 2025 – Jan 2026

Developed a six-stage instrumentation framework profiling token usage and latency across LLM hosts, MCP clients, and tool servers; benchmarked on 20 MCP servers and 169 tools.
