# Sumera Anjum — personal academic website (warm, original-style edition)

This version was revised from the **first academic-site package**, not from the blue-background redesign. It uses a cream-white background, subtle blue text links, simpler publication formatting, and first-person writing.

## Pages
- `index.html` — personal academic introduction and selected publications
- `research.html` — research in prose, without numbered cards
- `publications.html` — compact bibliography with search, year filters, summaries, and BibTeX
- `projects.html` — selected and ongoing work
- `teaching.html` — courses and mentoring with Fall / Summer academic terms
- `talks.html` — talks and presentations
- `service.html` — professional service
- `news.html` — academic updates
- `life.html` — beyond research
- `cv.html` — web CV and link to existing PDF

## Upload to GitHub Pages
1. Back up your repository first. Prefer testing in a branch (e.g. `human-refresh`).
2. Extract this ZIP. Upload files from inside the folder to the *root* of `sumera21/sumera-anjum`. Do not upload the enclosing directory.
3. Keep the existing `images/SAnjum.png` and `files/Sumera_Anjum_CV.pdf` from your repository. These assets are not included in this ZIP.
4. Publish from the branch set in Settings > Pages. Test all navigation and publication details.

Do not run a generator; all HTML pages are already included. You can edit page text directly in each HTML file. The shared look is controlled in `style.css`.
