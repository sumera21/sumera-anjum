Research

My work spans reliable language models, LLM agent systems, and generative AI for quantum computing. I’m especially interested in careful experiments that reveal where existing methods succeed—and where they don’t.

Trustworthy language models

Language models can produce convincing answers that are not necessarily correct. I’m interested in how we evaluate those answers, especially when the same factual claim is expressed in different languages or grounded in different sources.

In Poly-FEVER, we studied multilingual hallucination detection using aligned factual claims across eleven languages. Earlier, through HALO, we examined how retrieval and context selection affect clinical question answering.

Related work Poly-FEVER (EMNLP Findings 2026) · HALO (CHASE 2025)

LLM agents and their computational costs

When an LLM starts calling external tools, the cost is no longer just the model’s response. Tool descriptions, returned data, orchestration, and repeated context all contribute to token usage and latency. I want to understand these costs before proposing ways to reduce them.

Our ProMCP work profiled token flow and latency across different stages of Model Context Protocol workflows. I’m continuing this line of research through my work on token economics and API cost reduction, including my visiting student project at Argonne.

Related work ProMCP (ACL Findings 2026) · Current projects

Generative AI for quantum computing

Quantum programs are difficult to assess by looking at their text alone. A program can resemble the expected solution while behaving differently when executed. My work explores how language models generate quantum code, and how we can evaluate the generated programs more meaningfully.

In Beyond Vibe Coding, we study code generation across multiple quantum frameworks with execution-aware evaluation. During Summer 2026, I also mentored an undergraduate project exploring LLM-generated hardware for quantum simulation.
